# R6 — Dispositions of Amendment 001 findings

Status: **Draft for the independent re-check** (2026-10-23). The findings and decisions D1–D26 are in `R6-amendment-001.md`. This file records, for each finding, the fix, where it lives, and the check that covers it. The four fix groups (database, security/base, core docs and schemas, charts/build) applied D1–D26 between `9bcb516` and `b26ff34`. The alignment round of 2026-10-23 (`9092845` and the commit adding this file) fixed six cross-group mismatches and two decisions that had not reached the documents (A-15, and D13 in the DOD-02 row).

**Evidence base.** `platform/tools/validate_all.sh --strict` passes with nothing skipped (2026-10-23, this branch). All of it is **offline**: no cluster, no GitHub ruleset or App, no built image or component. "Runtime" below names the verification item that a real install must still pass.

**Status values**

| Status | Meaning |
|---|---|
| Closed — tested | The fix is in code, schema or manifests, and an automated check in `validate_all.sh` fails if it is removed (mutation-checked where noted) |
| Closed — config tested, runtime open | Policy or configuration is in place and checked offline; enforcement depends on a component or cluster behaviour that is not built or not run yet |
| Closed — documented | The finding was about documents; the corrected text is in place. Nothing executable to test |
| Partly closed | Part of the fix is in place; the remainder is named |
| Operator | Needs an operator decision or action; the agent side is done |

Abbreviations. Tests: `db:` = `platform/db/test_schema.py`, `adm:` = `platform/tools/admission/cases.py` case name, `chart:` = `platform/tools/charts/check_charts.py` case, `cfg:` = `platform/tools/validate_projects.py --self-test` case, `job:` = `platform/controller/test_jobspec.py`, `roles:` = `platform/tools/test_gen_role_configmap.py`, `schema:` = `platform/schemas/test_schemas.py`. Docs are cited by number (`19-…` = `19-postgresql-state.md`).
